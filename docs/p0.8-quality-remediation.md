## Keputusan

P0.8 memperkuat eksperimen Suggestion tanpa mengaktifkan Release atau
TestFlight. Baseline deterministik sekarang dapat diuji terhadap seluruh
fixture, sementara mode Hybrid dan Qwen langsung dapat menjalankan benchmark
model yang sama melalui alur lengkap:

```text
Dokumen/fixture
  → segmentasi
  → retrieval BM25 per target
  → Qwen atau aturan deterministik
  → parser enam baris
  → safety validator
  → hasil diterima / dipulihkan / ditolak
  → ringkasan benchmark
```

Keputusan saat ini:

- **GO untuk eksperimen Debug bounded:** ya.
- **GO untuk baseline deterministik:** ya, seluruh expected signal fixture lulus.
- **GO untuk Qwen-only suggestion cards:** belum.
- **GO untuk Release networking/TestFlight:** belum.
- **GO untuk perubahan dokumen otomatis:** tidak.

## Perubahan implementasi

### Review mode dan model

Panel Debug menyediakan tiga strategi:

1. `Baseline aman` — tidak memuat model; hanya aturan deterministik yang
   eksplisit untuk koreksi bahasa berisiko rendah dan replacement canonical
   glossary.
2. `Hybrid: model + guard` — mencoba Qwen, lalu hanya memulihkan output yang
   ditolak jika ada fallback deterministik yang aman.
3. `Qwen langsung` — menampilkan hasil yang lolos validator tanpa pemulihan,
   sehingga format adherence dan kualitas model dapat dibandingkan secara jujur.

Model yang tersedia:

- `mlx-community/Qwen3.5-2B-4bit`, revision
  `674aaa7240b91e8012fcad5d791b7dfe5ba90207` sebagai baseline.
- `mlx-community/Qwen3-4B-4bit`, revision
  `4dcb3d101c2a062e5c1d4bb173588c54ea6c4d25` sebagai pembanding Debug
  opsional. Model ini berasal dari [repository MLX text-generation Qwen3 4B](https://huggingface.co/mlx-community/Qwen3-4B-4bit)
  dan tidak diunduh oleh build atau unit test.

Model container tetap dicache per variant. Benchmark memproses fixture secara
berurutan, sehingga cancellation tidak memulai fixture berikutnya.

### Baseline deterministik

Rules yang sengaja dibatasi:

- `wajib untuk` → `wajib` sebagai grammar.
- `ditanda tangani` → `ditandatangani` sebagai spelling.
- `di simpan` → `disimpan` sebagai spelling.
- Definisi glossary yang cocok secara utuh → term canonical `G1`, dengan
  punctuation akhir di luar source span.

Replacement terminologi mendapat pengecualian safety hanya jika:

- `GLOSSARY_ID` menunjuk kandidat `G1` yang disediakan;
- replacement sama persis dengan term canonical dari store; dan
- original cocok dengan definisi glossary lengkap, termasuk bentuk definisi
  dengan prefix `Term adalah/ialah/merupakan`.

Teks yang kebetulan memiliki `G1` tetapi bukan definisi glossary tidak dapat
melewati pemeriksaan angka, modalitas, defined terms, atau token terlindungi.

### Benchmark

Tombol benchmark mengikuti strategi yang dipilih. Baseline dijalankan secara
sinkron dan selesai tanpa model. Mode Hybrid/Qwen langsung memanggil service
Qwen per fixture, mengumpulkan output di memori, lalu menerapkan parser dan
validator yang sama dengan single-document Run.

Panel menampilkan:

- jumlah fixture yang lulus expected signal;
- actual status dan replacement bila ada;
- durasi benchmark;
- ringkasan processed, suggestion, needs-review, no-suggestion, recovered,
  rejected, dan skipped;
- raw output rejection hanya pada disclosure Debug yang sudah ada.

## Hasil runtime manual

Benchmark dijalankan pada build Debug arm64 di Mac Apple Silicon, dengan
thinking off dan delapan fixture bawaan. Model Qwen3 4B diunduh pada
pemakaian pertama; proses berikutnya menggunakan cache lokal.

| Mode | Model | Expected signal | Waktu | Hasil utama |
| --- | --- | ---: | ---: | --- |
| Baseline aman | aturan deterministik | **8/8** | 0,39 dtk | 3 suggestion, 5 no-suggestion, 0 rejected |
| Hybrid | Qwen3.5 2B | **8/8** | 18,57 dtk | 8 output Qwen ditolak lalu 8 dipulihkan oleh fallback deterministik; 3 suggestion, 5 no-suggestion |
| Qwen langsung | Qwen3.5 2B | **0/8** | 13,18 dtk | 8 output ditahan/ditolak; tidak ada hasil tervalidasi |
| Qwen langsung | Qwen3 4B | **1/8** | 31,41 dtk | 1 suggestion model diterima, 7 output ditolak |

Satu hasil Qwen3 4B yang diterima adalah penggantian `notice` menjadi
`pemberitahuan` pada fixture `Borrower`/`Lender`. `Borrower`, `Lender`, angka,
dan tenggat tetap utuh sehingga memenuhi expected signal invariance untuk
fixture tersebut. Qwen3.5 2B tidak menghasilkan output langsung yang lolos;
hasil Hybrid yang tampak berhasil seluruhnya berasal dari fallback deterministik.

Dengan demikian, baseline deterministik memenuhi tiga kasus bahasa yang
dibatasi dan seluruh safety/invariance fixture. Namun Qwen-only hanya memenuhi
1/8 fixture pada pembanding 4B dan 0/8 pada Qwen3.5 2B. Ini adalah bukti
kelayakan guard dan baseline, bukan bukti bahwa model kecil sudah cukup baik
untuk suggestion cards.

## Prosedur benchmark runtime manual

Benchmark model harus dijalankan dari build Debug pada Mac Apple Silicon:

1. Buka `AI Connector — Test Document` dari Dashboard.
2. Pada panel Suggestion, pilih `Dummy Sample` jika ingin menguji satu fixture,
   atau gunakan tombol benchmark untuk seluruh fixture.
3. Pilih `Hybrid: model + guard` dan `Qwen3.5 2B (baseline)`.
4. Pastikan thinking off, lalu jalankan benchmark. Pada pemakaian pertama,
   tunggu model selesai diunduh; run berikutnya memakai cache.
5. Catat status actual, replacement, origin, rejection count, durasi, dan
   apakah ada output yang ditolak.
6. Ulangi dengan `Qwen langsung` untuk mengukur model tanpa recovery.
7. Ulangi dengan `Qwen3 4B (pembanding)` hanya jika waktu dan storage cukup.
8. Jalankan satu fixture dengan thinking on untuk memastikan reasoning tidak
   tampil dan incomplete thinking ditangani.

P0.8 dianggap siap menuju quality review berikutnya jika benchmark model
menunjukkan sedikitnya dua dari tiga fixture bahasa berguna dan seluruh fixture
safety tidak mengubah substansi, angka, defined terms, atau sumber. Hasil
baseline deterministik yang lulus tidak boleh dipakai sebagai bukti bahwa
Qwen-only sudah lulus.

## Batasan dan langkah berikutnya

- Panel tetap Debug-only dan Release tetap tanpa outbound network.
- Tidak ada Accept/Reject, auto-rewrite, structured suggestion cards, vector
  database, embedding, RAG baru, fine-tuning, telemetry, atau cloud inference.
- Output Qwen yang tidak memenuhi kontrak tetap ditolak; recovery tidak
  mengubah dokumen.
- Jika Qwen3.5 2B dan Qwen3 4B masih gagal pada safety atau format, langkah
  berikutnya adalah memperluas deterministic typo/rule engine atau meninjau
  model yang lebih besar dengan fixture yang sama—bukan langsung mengaktifkan
  TestFlight.
