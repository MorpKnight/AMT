# P0.9 — Validasi Qwen3.5 Indonesian Legal 4B

Status implementasi: **benchmark model selesai dijalankan** pada 28 Agustus 2026
di MacBook Pro arm64, macOS 26.5.2. Report JSON lengkap berada sementara di
`/private/tmp/amt-p09-legal-4b.json`; artefak tersebut tidak dimasukkan ke Git
karena berisi output diagnosis fixture.

## Tujuan dan batas keputusan

P0.9 menguji apakah `morpknight/qwen3.5-4b-indonesian-legal-mlx-4bit` layak
menjadi model utama pada Suggestion Debug ketika output melewati segmentasi,
retrieval glossary, parser enam baris, safety validator, dan fallback
deterministik. Ini bukan pengujian ketepatan hukum dan bukan persetujuan untuk
Release/TestFlight.

- **Given:** runtime MLX, cache Hugging Face, cancellation, segmentasi, BM25,
  parser, validator, dan fallback sudah tersedia dari P0.8.
- **Assumed:** model yang diadaptasi ke bahasa hukum Indonesia mungkin lebih
  patuh terhadap fixture AMT, tetapi domain adaptation tidak dianggap sebagai
  sumber hukum.
- **Needs validation:** kepatuhan format, kecocokan expected signal, truncation,
  repetition, reasoning leak, dan preservasi substansi pada runtime macOS.

## Runtime profile

- Default Debug: **Hybrid + Legal 4B**, thinking off.
- Baseline historis: `mlx-community/Qwen3.5-2B-4bit`; cache tidak dihapus.
- Legal 4B non-thinking: maksimum 256 token, greedy `temperature=0`, `topP=1`,
  `topK=0`, tanpa penalty, seed 42.
- Baseline 2B non-thinking: maksimum 256 token, temperature 0,2, top-p 0,9,
  top-k 20, presence penalty 0, seed 42.
- Thinking eksperimental: maksimum 768 token, temperature 0,6, top-p 0,95,
  top-k 20, presence penalty 0, seed 42.
- Setiap segmen memakai `ChatSession` baru. Streaming dikumpulkan di buffer
  internal dan completion metrics diambil melalui `streamDetails`.
- Stop reason `length` ditolak sebelum parser. Hybrid boleh memakai fallback
  deterministik; Qwen-only tetap dicatat sebagai rejection.
- Output yang mengandung marker reasoning/template disimpan sebagai penanda
  redacted saja. Tidak ada teks reasoning di output, log, atau report.

## Matrix benchmark

Harness opt-in menjalankan matrix berikut secara berurutan menggunakan delapan
fixture bawaan:

1. baseline deterministik 8 fixture;
2. Legal 4B Qwen-only 8 fixture;
3. Legal 4B Hybrid 8 fixture;
4. satu fixture thinking untuk memeriksa leak/incomplete thinking;
5. cached load dan cancellation smoke test.

Setiap record menyimpan candidate glossary, output diagnosis yang aman, status
parser/validator, origin model atau fallback, rejection reason, prompt/generation
tokens, durasi, stop reason, repeated 6-gram ratio, dan expected-signal pass/fail.

Command (Xcode 26 membutuhkan prefix `TEST_RUNNER_` agar environment diteruskan
ke proses XCTest; test membaca nama setelah prefix tersebut dilepas):

```bash
TEST_RUNNER_AMT_RUN_P09_MODEL_BENCHMARK=1 \
TEST_RUNNER_AMT_P09_REPORT_PATH=/private/tmp/amt-p09-legal-4b.json \
xcodebuild \
  -project AMT.xcodeproj \
  -scheme AMT \
  -configuration Debug \
  -destination 'platform=macOS,arch=arm64' \
  -derivedDataPath /private/tmp/AMT-P09-DerivedData \
  CODE_SIGNING_ALLOWED=NO \
  -only-testing:AMTTests/AIConnectorModelBenchmarkTests \
  test
```

Test tanpa environment variable tersebut melakukan `XCTSkip` sebelum membuat
service atau memanggil MLX, sehingga unit test reguler tidak mengunduh model.

## Quality gate

Qwen-only hanya dapat diberi keputusan **GO untuk eksperimen Debug** jika:

- sedikitnya 2 dari 3 fixture utility (grammar, spelling, terminology) sesuai
  expected signal;
- 5 fixture neutral/safety semuanya aman;
- output unsupported tetap ditolak oleh boundary;
- tidak ada token-limit hit, repeated 6-gram ratio `>= 0,2`, reasoning leak,
  atau sumber hukum buatan;
- cancellation tidak melanjutkan fixture berikutnya.

Jika salah satu safety case gagal, keputusan menjadi **NO-GO** dan Hybrid tetap
menggunakan fallback deterministik. Tidak ada perubahan otomatis pada dokumen,
Accept/Reject, Release networking, atau aktivasi TestFlight sebagai akibat dari
hasil benchmark ini.

### Rincian hasil

- Baseline deterministik lulus seluruh delapan fixture: tiga utility dan lima
  neutral/safety.
- Qwen-only menghasilkan satu saran grammar yang lolos parser/validator, tetapi
  span-nya adalah seluruh kalimat sehingga tidak sesuai expected signal yang
  mengharapkan penggantian `wajib untuk`. Tujuh output lainnya ditolak karena
  `NO_SUGGESTION` masih mengisi `ORIGINAL` atau `REPLACEMENT`, atau karena
  kombinasi field tidak konsisten. Dua output juga melewati ambang repetition.
- Hybrid memulihkan output yang ditolak dengan aturan deterministik. Lima kasus
  neutral/safety tetap aman dan dua dari tiga utility sesuai expected signal;
  namun quality gate tetap NO-GO karena dua repetition terdeteksi pada output
  model. Saran yang tampil pada mode ini dapat berasal dari fallback dan bukan
  bukti bahwa Legal 4B sendiri lulus.
- Thinking berhenti sebelum `</think>` pada fixture pertama. Tidak ada isi
  reasoning yang ditulis ke report; hanya pesan aman untuk mencoba non-thinking.
- Cancellation smoke test lulus setelah service memeriksa `Task` cancellation
  setelah stream berakhir. Progress fixture tidak bergerak ke fixture kedua.
- Result bundle XCTest menunjukkan satu test passed, tanpa skip atau failure.

## Keputusan

Status P0.9 adalah **NO-GO untuk Qwen-only**. Legal 4B belum boleh dianggap
sebagai model utama yang dapat menghasilkan saran langsung. Default tetap
Debug-only Hybrid + Legal 4B dengan fallback deterministik; Release tetap tanpa
tombol analisis dan tanpa outbound networking. Tidak ada perubahan dokumen
otomatis atau aktivasi TestFlight.

Kegagalan utama berada pada format/contract adherence dan repetition, bukan pada
retrieval source ownership atau safety validator: seluruh lima fixture
neutral/safety pada Hybrid tetap aman, tidak ada token-limit hit, reasoning leak,
atau sumber hukum buatan. Langkah berikutnya adalah membandingkan baseline
deterministik dengan model/rule engine yang lebih cocok untuk span-level editing
atau memperbaiki data/prompt pada benchmark terpisah; benchmark gate ini tidak
boleh dituning menggunakan hasil fixture yang sama.
